# How to Add Your Profile Photograph

The interactive 3D Identity Flip Card in the **About Me** section displays your photograph on the front panel of the card, designed to resemble a premium lanyard ID pass.

Follow these simple steps to add your photo:

1. **Get your photograph**: Choose the image file you want to use.
2. **Rename the image**: Rename the image file exactly to:
   ```
   yuvan_profile.jpg
   ```
   *(Note: Ensure the file extension is lowercase `.jpg` and not `.jpeg` or `.PNG`)*
3. **Copy to the public folder**: Place the renamed image file into the following directory inside your project:
   ```
   c:\Users\A.YUVAN AVINASH\Downloads\Portfolio-\public\
   ```
   So the final path of the image will be:
   ```
   c:\Users\A.YUVAN AVINASH\Downloads\Portfolio-\public\yuvan_profile.jpg
   ```
4. **Refresh the website**: Save the file and reload the website. Clicking the card will flip it to show your photograph alongside your primary and secondary focus matrices!
