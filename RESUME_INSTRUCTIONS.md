# How to Upload Your Resume PDF

The **Download Resume** buttons in the Hero section and About Me section are configured to download your resume file (`resume.pdf`).

Follow these simple steps to upload your resume:

1. **Prepare your Resume PDF**: Ensure your resume is saved as a PDF document.
2. **Rename the file**: Rename your PDF file exactly to:
   ```
   resume.pdf
   ```
   *(Note: Ensure the file extension is lowercase `.pdf` and not `.PDF`)*
3. **Copy to the public folder**: Place the PDF file into the `public` directory inside your project workspace:
   ```
   c:\Users\A.YUVAN AVINASH\Downloads\Portfolio-\public\
   ```
   So the final file path is:
   ```
   c:\Users\A.YUVAN AVINASH\Downloads\Portfolio-\public\resume.pdf
   ```
4. **Test on Website**:
   - Reload your website.
   - Click the **DOWNLOAD RESUME** button in the Hero section or About section.
   - The browser will automatically open/download your PDF named `Yuvan_Avinash_Resume.pdf`.
